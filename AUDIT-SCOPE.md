# Audit scope

Included: current Compose declarations with mandatory private interpolation,
public env values, sanitized declarative examples and field mappings.
Excluded: runtime/config documents owned by applications, database/volume
contents, certificates/keys, custom extension code, historical backups,
old dotenv copies, deployment-specific helper notes and original Git history.

Private import/render/application evidence stays outside this candidate.
An offline configuration-equivalence check is not evidence that a privileged
Infisical import or Agent application has already happened.
